# web-idor (web, easy)

A small notes service runs on `http://localhost:8081`.

You are the user `guest`. Your API token is in `guest-token.txt`. Send it in
the `X-Token` header.

- `GET /api/notes` lists your notes.
- `GET /api/notes/<id>` returns one note.

The administrator keeps a private note. Read it.

Flag format: `flag{32 hex characters}`.
